# Step 2C.2B — Homepage and Entity Presentation Contract

## Status

Source-verified implementation complete. Live WordPress/WPGraphQL execution is
deferred until the final installation and staging-validation phase.

This package is an intermediate backend contract. It must not be accepted for
public production until Step 2C.2C adds and validates object-level GraphQL
visibility for Investments and Testimonials.

## Added GraphQL field groups

| Parent type | Field | Explicit field-group type |
|---|---|---|
| `Page` | `siraHomepage` | `SiraHomepage` |
| `SiraCompany` | `companyDetails` | `SiraCompanyDetails` |
| `SiraInvestment` | `investmentDetails` | `SiraInvestmentDetails` |
| `SiraTestimonial` | `testimonialDetails` | `SiraTestimonialDetails` |
| `SiraPartner` | `partnerDetails` | `SiraPartnerDetails` |

Nested group and repeater type names are generated by WPGraphQL for ACF and are
not frozen by this source package. They must be recorded by the deferred live
schema inventory before frontend code generation is finalized.

## Homepage ownership

The field group is attached only to the configured WordPress front page and is
explicitly mapped to GraphQL `Page`.

The contract uses:

- one `variant` radio field;
- one fixed Group homepage group;
- one fixed shared Branch homepage group;
- repeaters for ordered slides, ticker items, metrics, and focus areas;
- typed ACF links;
- typed media fields;
- typed post relationships;
- Business Unit taxonomy relationships.

It does not use Flexible Content or arbitrary page-builder JSON.

## Group homepage

The Group contract covers:

- hero and ordered hero slides;
- ticker;
- latest/curated editorial updates;
- selected companies;
- About copy and metrics;
- public investment section;
- selected services;
- selected projects;
- selected editorial content;
- selected testimonials;
- selected partners;
- contact-section copy and form routing context.

Autoplay timing, transitions, image scrims, responsive behavior, section order,
motion, and design tokens remain frontend-owned.

## Shared branch homepage

One Branch contract covers Consulting, Healthcare, Lifestyle, and Real Estate:

- hero;
- statistics;
- overview;
- focus areas;
- selected projects;
- selected/latest editorial items;
- contact-section copy;
- optional footer-label overrides.

Branch identity remains controlled by the trusted site key and `siraBrand`.

## Company classification

`sira_business_unit` now also applies to `sira_company`.

This is the canonical branch relationship for Group portfolio cards. No
duplicate Company branch-key ACF field is introduced.

## Company details

Public presentation fields:

- operating status;
- external website URL;
- short descriptor;
- card image override.

## Investment details

Fields:

- public-display approval flag;
- ticket-size label;
- related Company;
- related Project;
- one-pager Document/Download/Whitepaper.

The public-display field defaults to false.

**Important:** Step 2C.2B does not yet make the post object private when this
flag is false. Do not publicly deploy this intermediate package without the
Step 2C.2C visibility safeguards.

## Testimonial details

Public presentation fields:

- role;
- organization;
- consent-approved flag;
- source URL.

The consent flag defaults to false.

The operational consent timestamp is stored but explicitly excluded from
GraphQL.

**Important:** Step 2C.2B does not yet make the post object private when
consent is false. Do not publicly deploy this intermediate package without the
Step 2C.2C visibility safeguards.

## Partner details

Fields:

- website URL;
- relationship label;
- logo alternative-text override.

The featured image remains the default logo source.

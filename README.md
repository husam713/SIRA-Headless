# SIRA Headless Platform

Local development workspace for the SIRA Enterprise headless migration.

## Structure

- backend: WordPress sira-core plugin
- frontend: Next.js multi-brand application
- tools: read-only inventory and migration utilities
- docs: architecture, validation, and operational documentation

# SIRA Atlas — creative prototype

An exploration of what the SIRA frontend could become. Static HTML/CSS/JS, no
build, no dependencies. Content is drawn from the live SIRA CMS (copy and
photography) and extended with clearly marked demo records so the experience
can be browsed end to end. Not production code; never imported by the app.

Preview:

    cd frontend/prototypes/sira-atlas
    python -m http.server 4173

then open http://localhost:4173/ — add `?lang=ar` for the Arabic / RTL mode.
